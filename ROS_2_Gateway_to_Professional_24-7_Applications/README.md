## 発表概要

ROSCon 2024での Dr.-Ing Denis Stogl（Stogl Robotics Consulting GmbH の所有者・CEO）と Sebastian Krauskopf（Bosch Rexroth AG のctrlX AUTOMATIONリードソフトウェアアーキテクト）による「ROS 2 Gateway to 24/7 Applications」の発表内容をまとめたものです。

## 主な課題：ROSと産業用PLCシステムの比較

### ROSの課題点
- 産業用フィールドバス接続性の欠如
- 産業機器向けの展開パイプラインが不十分
- システムの複雑さ
- シンプルなロジックプログラミングの難しさ
- Linux中心のツールチェーン
- セットアップの個別性（多くの場合、すべてのセットアップが独自）
- セキュリティ強化のための高い労力
- 高レベルプログラミングの複雑さ

### 産業用PLCシステムの利点
- 産業グレードの長期使用可能なハードウェア
- フィールドバス接続性
- 認証された安全性（IEC 61508）
- 多様なセンサー、アクチュエータ、入出力デバイス
- PLCプログラミング
- スケーラブルなハードウェアポートフォリオ

### 産業用PLCシステムの課題点
- Windowsベースのエンジニアリングツール
- 独自インターフェース
- 高度なプログラム実行能力の制限
- 科学的データ処理の限界
- ベンダーロックイン（IEC 61131-3の普及度低さ、開発者不足）

### ROSの強み
- 最先端アルゴリズム（知覚、動作計画など）
- 物理シミュレーション
- 豊富なハードウェアドライバーエコシステム
- 複雑なデータの視覚化
- 機械学習の統合
- 複雑なデータでの簡易プロセス間通信
- 複雑なデータロギング

## 解決策：ctrlX OSオートメーションプラットフォーム

### 主な特徴
- 高レベルプログラミング言語（C/C++、Python、Golangなど）
- オープンソース・コミュニティフレンドリーな標準
- オープンでモジュラーな拡張可能アーキテクチャ
- ソフトウェアコンテナ
- Linux PREEMPT_RT
- オープンソースSDK
- Webベース構成
- IEC 62443認証セキュリティ
- リモートアクセス
- ソフトウェア管理

### アーキテクチャ
1. **基盤**:
   - Linux リアルタイムカーネル（PREEMPT_RT）
   - Ubuntu Coreとスナップコンテナ
   - 組み込みデバイス/産業用PC/仮想マシン上で動作可能

2. **中核コンポーネント**:
   - ctrlX データレイヤー（リアルタイム対応のセキュアなメッセージブローカー）
   - レポジトリからの産業用アプリの簡単インストール（EtherCAT、Soft PLCランタイム、OPC UAなど）
   - オープンソースSDKとアプリケーションサンプルに基づく独自のROS 2アプリケーション拡張

## 実装例

### 例1：産業用コントローラ（ctrlX CORE）へのROS 2アプリのデプロイ
- ctrlX CORE X7へのROS 2アプリ（スナップ）の直接デプロイ
- ROS 2ベース（Humble/Jazzy）
- TCP/IP、UDPを介した通信
- HDMIを介した機械視覚化

### 例2：ROS 2アプリから産業用ロボットへの接続
- ROS 2アプリ（スナップ）からctrlX CORE X5への接続
- ROS 2ベース（Humble）とROSブリッジスイート
- ctrlxdatalayer.soを介した通信
- IOマネージャーとモーションパブリッシャー（C++）
- TCP/IPを介したエンジニアリングPC接続
- ctrlX I/O、センサー、ドライブとのEtherCAT接続

### 例3：ROS2_controlを使用したKukaロボットのハードリアルタイム制御
- ctrlX CORE X7上でのリアルタイムバンドル（スナップ）
- コントロールボックスアプリ
- DataLayer HWインターフェースを介したRT通信
- ロボティックセルマネージャー
- 6軸ロボットとのストリーミングインターフェース（2ms周期）
- UDP/IP、EtherCAT、CanOpenプロトコル

## 結論と展望

- ROS 2と産業用機器は効果的に連携可能
- より詳細な情報は以下で入手可能:
  - GitHub: https://github.com/boschrexroth
  - コミュニティ: https://developer.community.boschrexroth.com
  - ROSCon: ブース11、Canonical

この統合により、ROSの強みである先進的アルゴリズムや豊富なツールと、産業用PLCシステムの堅牢性、安全性、フィールドバス接続性を組み合わせることで、24時間365日稼働する産業用ロボットアプリケーションの構築が可能になります。
